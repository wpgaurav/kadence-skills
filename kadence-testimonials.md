## Best Practices

1. **Authenticity**: Use real names and photos when possible
2. **Specificity**: Include company names and roles
3. **Results**: Mention specific outcomes when available
4. **Visual balance**: Consistent card heights in grids
5. **Star ratings**: Use `fe_star` icon with `#fbbf24` (amber) color
6. **Quote marks**: Optional large quote icons add visual interest
7. **Responsive**: Cards should stack gracefully on mobile
